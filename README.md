### Installation

To set up your development environment, follow these simple steps:

1. Clone the repo
   ```sh
   git clone https://github.com/gdmartinezsandino/presupco.git
   ```

2. Server Setup:
  Navigate to the server directory.
  Follow the instructions in the [server README](https://github.com/gdmartinezsandino/presupco/src/master/server/README.md) for setting up the server.
  
3. WebApp Setup:
  Navigate to the webapp directory.
  Follow the instructions in the [webapp README](https://github.com/gdmartinezsandino/presupco/src/master/webapp/README.md) for setting up the web application.

4. Mobile Setup:
  Navigate to the mobile directory.
  Follow the instructions in the [mobile README](https://github.com/gdmartinezsandino/presupco/src/master/mobileapp/README.md) for setting up the web application.
